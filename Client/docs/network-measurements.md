# Сеть: два сценария по 600 секунд

Дата: 2026-10-06. Исходный экспорт `8c953993` + SQLite запускался отдельно на loopback:8787; Kotlin Ktor/OkHttp работал с Server v3 + PostgreSQL 17 на loopback:8080. Оба сценария: локальная партия 10×14, два короля уже установлены; `smile` каждые 9 секунд. Инициализация исключена. Спокойный сценарий — главное меню без действий.

| Метрика за 10 минут | Старый, покой | Kotlin, покой | Старый, партия | Kotlin, партия |
|---|---:|---:|---:|---:|
| HTTP-запросы | 59 | 0 | 732 | 66 |
| Исходящие HTTP payload, байт | 118 | 0 | 4 736 | 6 770 |
| Входящие HTTP payload, байт | 24 603 | 0 | 3 284 391 | 7 715 |
| Входящие WS data-сообщения | 0 | 0 | 0 | 66 |
| Входящие WS payload, байт | 0 | 0 | 0 | 34 055 |
| Открытые WS-соединения | 0 | 1 | 0 | 1 |
| Переподключения Kotlin | — | 0 | — | 0 |

В покое регулярные HTTP-загрузки отсутствуют: сокращение 100%, цель ≥90% достигнута в данном сценарии. В партии HTTP сократился на 91,0%, сумма полезных данных — с 3 289 127 до 48 540 байт (98,52%). Один ход не скачивает полный профиль/каталог.

Heartbeat учтён отдельно: Server отправляет WS ping раз в 20 секунд, OkHttp отвечает pong. Примерно 30 пар control frames за 600 секунд; они **не включены** в счётчики data-сообщений и байтов таблицы. Заголовки HTTP, TCP/IP, TLS и WS framing также исключены. Нулевой payload в покое не означает отсутствие сетевого трафика.

Измеренный p95 исходной HTTP-команды — 29,26 мс; Kotlin от отправки команды до применимого события — 242 мс. Это разные границы измерения: первую нельзя называть задержкой отрисовки старого клиента. Частота старого polling 900 мс воспроизведена HTTP-драйвером из `next.mjs`; реальная браузерная и Android-отрисовка в эти цифры не входят. Прямое сравнение задержки видимого хода на устройствах ещё требуется. 10-минутный Kotlin-тест выполнялся на JVM, не на Android.

Воспроизведение: `node Client/scripts/measure-baseline.mjs` при запущенном оригинальном Worker; `SYMBOLS_MEASURE=600 SYMBOLS_TEST_URL=http://127.0.0.1:8080 ./gradlew :core:test --tests '*TrafficMeasurementTest' --rerun-tasks` из Client. Raw JSON сохранён рядом в `measurements/`. Использовать только отдельную синтетическую БД.
