## Проверка сертификатов

```sh
apksigner verify --verbose --print-certs symbols-rustore.apk
keytool -printcert -jarfile symbols-play.aab
```

Вторая команда показывает сертификат загрузки AAB, а не гарантирует подпись APK из Play. Скачай APK из App bundle explorer/установи закрытый Play-тест и отдельно проверь его `apksigner`. При Play App Signing заранее импортируй согласованный app signing key владельца: [официальная инструкция](https://developer.android.com/studio/publish/app-signing). Не выбирай необратимый ключ по умолчанию без решения владельца.

Хеши файлов: PowerShell `Get-FileHash -Algorithm SHA256 <file>` или `sha256sum <file>`. Хранить хеш, versionCode, git SHA, параметры окружения без секретов и SHA-256 сертификата рядом с архивом выпуска. Подпись debug/qa не пригодна для публикации.
