# Данные и privacy policy — проект для владельца

Это инвентаризация поведения кода, а не отправленная анкета и не действующая политика. Владелец должен добавить оператора, адрес/контакт, страны обработки, инфраструктурных обработчиков, сроки резервных копий и применимые основания обработки.

| Данные | Назначение / хранение | Отображение другим игрокам |
|---|---|---|
| ID аккаунта, ник, выбранная аватарка/рамка | Server/PostgreSQL, работа аккаунта/матча/рынка | Публичные игровые поля в матче и предложениях |
| Хеши токена и кода восстановления | Server/PostgreSQL, аутентификация | Нет |
| Токен сессии | Android Keystore + AES-GCM noBackupFilesDir | Нет, только защищённый Authorization |
| Баланс игровых рубинов, предметы, XP, звание, история, команды | Server/PostgreSQL; приватное состояние в оперативной памяти Android | Часть результатов/звания видна соперникам; чужой инвентарь скрыт |
| Жалоба: отправитель, цель, причина | Server reports, доступ оператора через admin CLI | Не публично |
| Блокировки | Server/PostgreSQL, ограничение взаимодействий | Список не публичен |
| IP и технические запросы | Сеть/лимиты Server; сроки и журналы прокси уточнить у владельца | Нет |
| Настройка уменьшения эффектов | Только DataStore на устройстве | Нет |

SDK: Kotlin/Coroutines/Serialization, AndroidX Compose/Lifecycle/DataStore/Activity, Ktor/OkHttp/Okio, AndroidSVG. Они нужны для работы приложения. Отдельных рекламных, аналитических, crash-reporting, push, платежных SDK нет. Google Play Services не требуется. Нет Advertising ID, контактов, геолокации, камеры, микрофона, SMS, загрузки пользовательских изображений.

Адреса: один выбранный API origin (HTTPS и WSS `/api/v3`), ссылки владельца privacy/support и `/account-deletion`. Реальные staging/prod домены ещё не предоставлены. Статические символы и PNG включены в APK; приложение не загружает Base64-изображения вместе с профилем.

Проект Data safety / RuStore: отметить сбор идентификатора пользователя, никнейма/игрового профиля, активности приложения/игровых действий и пользовательского текста жалоб в подходящих категориях актуальной формы. Назначение — функциональность, управление аккаунтом, безопасность/предотвращение злоупотреблений. Не заявлять «данные не собираются». Публичные игровые поля и передача хостингу требуют отдельной классификации по определениям формы. Игровые рубины не являются платёжными данными банковских карт.

Транспорт production зашифрован; токены не включаются в URL, логи или backup. Защищённые экраны кода восстановления/входа запрещают скриншоты. Аккаунт удаляется через Настройки → Удалить аккаунт с подтверждением; веб-путь работает по коду без Android-приложения. Активные данные удаляет Server, срок хранения резервных копий обязан назвать оператор. Основание: [Google Play account deletion](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en).

Каркас политики для публикации владельцем:

«Символы» обрабатывает данные игрового аккаунта, перечисленные выше, для сохранения прогресса, проведения партий и защиты игроков. Код восстановления предоставляет доступ к аккаунту: храните его приватно. Для удаления используйте кнопку в приложении или веб-страницу удаления. Вопросы обработки направляются оператору по его опубликованному контакту. Политика должна назвать оператора и обработчиков, реальные адреса, сроки хранения активных данных/резервных копий, применимые права пользователя и дату вступления в силу.

Этот каркас нельзя публиковать с незаполненными сведениями.
