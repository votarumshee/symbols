# RuStore — проект карточки, не отправлен

Название: **Символы**. Предлагаемая категория: Игры / Стратегии.

Краткое описание: **Пошаговые дуэли: защищай короля, собирай символы и играй с друзьями.**

Полное описание:

Символы — тактическая игра с королями, стрелочками, блоками и усилителями. Направляй атаки, защищай свои фигуры и продумывай следующий ход.

Доступны дуэли, команды 2×2, испытания звания, комнаты по коду и режим для двух игроков на одном устройстве. Два размера поля — 10×14 и 28×20 — позволяют выбирать масштаб партии. Большое поле можно прокручивать и увеличивать.

Игра сохраняет опыт, звания, историю и коллекцию предметов на сервере. Улучшай символы и меняй оформление. Магазин, кейсы и рынок работают за игровые рубины, без платежей реальными деньгами. Вероятности выпадения доступны в карточке кейса. Рекламы нет.

Нужен интернет. Google Play Services для игры не требуются. Аккаунт прежней браузерной версии восстанавливается по коду после серверного переноса данных.

Что нового 1.0.0: «Первая версия для Android: нативная игра, восстановление аккаунта, инвентарь и рынок». Текст применяется после прохождения приёмки.

## Проверка загрузки

1. Владелец подтверждает пакет com.votarumshee.symbols и versionCode=1 либо предоставляет историю прежних выпусков.
2. Подписанный production APK собирается с app signing key владельца. Сравнить SHA-256 с сертификатом **установленного** APK Google Play; upload key AAB для этого не подходит.
3. Проверить обновление без удаления приложения, сохранение аккаунта, Android 26/36 и устройство без Google-сервисов.
4. Прикрепить действующие контакты, политику и внешнее удаление аккаунта. Заполнить анкету данных по data-declarations.md.
5. Возраст, страны и описание кейсов согласовать с владельцем. Не включать рекламные/платёжные SDK ради магазина.
6. Иконка `graphics/icon.png` и отдельный набор `rustore/screenshots/` (PNG 1080×1920) подготовлены из настоящего Android devQa. Обновить снимки на утверждённом production-кандидате; проверить актуальные поля RuStore Console.
7. Модератор может зарегистрироваться и сыграть с ботом; импорт проверяет по отдельному синтетическому коду в закрытых данных модерации.
8. Владелец утверждает конкретный APK и заполненные поля. Только затем загружать/отправлять.

Официальные источники, проверять снова в день отправки: [публикация](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication), [подпись](https://www.rustore.ru/help/guides/sign-apk), [требования к приложениям](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps).
