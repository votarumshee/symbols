## Проверки из внешней среды

Проверка TLS выполнена обычным доверенным SSL-контекстом, без отключения проверки сертификата. Подтверждены TLS 1.3, имя домена и issuer Let's Encrypt YE2.

| Запрос | Результат |
|---|---|
| HTTP `/` | 308, переход на HTTPS того же домена |
| HTTPS `/` | 503, `Service is being prepared` |
| HTTPS `/api/v3/bootstrap` | 503, тот же maintenance-ответ |
| HTTPS `/metrics` | 404 |

HTTPS-ответы содержат HSTS max-age=31536000. Игровое API намеренно не открыто: Caddy ещё не направляет запросы на приложение. Публичный WSS не проверен, поскольку игровой upstream пока закрыт. Приложение и PostgreSQL продолжают работать внутри установленного окружения, API на хосте привязан к loopback.
