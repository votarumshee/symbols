Удаление аккаунта «Символы»

Введите код восстановления своего аккаунта. Подтверждение удалит профиль, баланс, инвентарь, сессии и историю. Открытые лоты отменяются, текущие партии прекращаются без наград. Действие необратимо. Восстановление по коду завершит другие сессии этого аккаунта. Резервные копии удаляются по сроку хранения оператора; уточнить его можно через поддержку.
